========================================

HOW TO VIEW THE SITE
---------------------
This is a static website — no build step or server required.
Simply open index.html in a web browser, or upload the whole
folder to any standard web host (the file paths are all relative).

IMPORTANT — ABOUT THE IMAGES
------------------------------
The images included in this package are original, elegant abstract
placeholder graphics generated specifically for this brand, using the
site's three-colour palette (ivory, dusty rose, champagne gold) with
simple line-art motifs (florals, rings, combs, droplets). They were
created this way deliberately: real photographs of the salon, its
services or clients were not available to use, and stock or Pinterest
photography could not be reused without a proper license.

Before the site goes live, replace the files in /images/ with real,
properly licensed photography — ideally your own salon and service
photos, or stock images you have purchased a commercial license for.
Keep the same filenames (see below) and the same 4:3 / 1:1 / 16:9
aspect ratios used by each section, and everything will drop in
without any code changes.

Image filename reference:

CUSTOMIZING CONTENT
--------------------
- Business name, address and phone number are already filled in
  throughout every page and the WhatsApp / Call Now buttons.
- Instagram and Threads links are wired up in the header/footer and
  on each page's social section.
- The Google Map on the About, Home and Contact pages uses a generic
  embed centered on Kadachanendhal, Madurai. For a pinpoint location,
  replace the iframe "src" with an embed link generated from Google
  Maps for your exact business listing (Google Maps > Share > Embed
  a map).
- The enquiry form on contact.html is front-end only: it validates
  input and shows a confirmation message, but does not send data
  anywhere yet. To actually receive enquiries, connect the form to
  an email/service endpoint (e.g. Formspree, a serverless function,
  or your own backend) and update the JS submit handler in
  js/script.js accordingly.
